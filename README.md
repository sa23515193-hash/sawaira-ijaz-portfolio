# Sawaira Ijaz — Premium Portfolio

A one-page React + Vite personal portfolio with black/pink/gold branding.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Customize

- Edit `src/main.jsx` for text, projects, links and contact details.
- Edit `src/styles.css` for the visual theme.
- Replace `public/Sawaira-Ijaz-CV.pdf` with an updated CV PDF whenever needed.
- If you want a profile photo, add it to `public/` and replace the SI initials block in `src/main.jsx`.

The WhatsApp button uses the supplied number and opens a direct chat.
